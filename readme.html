Ontology Copilot 0.9.25

A Protégé plugin that helps you draft and edit ontologies with an LLM assistant, using methods from peer-reviewed research (NeOn-GPT, Ontogenia, RIGOR-Lite and a direct draft). Every change is shown in Change Preview first; nothing changes until you press Apply.

New in 0.9.25: the main buttons are blue on Windows and Linux too (in 0.9.24 they looked greyed out there).

Tested with Protégé 5.6.7 only. It may not work with other Protégé versions.

After installing, restart Protégé and open Window > Views > Ontology views > Ontology Copilot (0.9.25). Then choose a model provider (OpenRouter, OpenAI, Anthropic, Google Gemini or a local Ollama) and enter your own API key in the plugin's Settings.
