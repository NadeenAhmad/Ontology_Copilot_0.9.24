Ontology Copilot 0.9.27

A Protégé plugin that helps you draft and edit ontologies with an LLM assistant, using methods from peer-reviewed research (NeOn-GPT, Ontogenia, RIGOR-Lite and a direct draft). Every change is shown in Change Preview first; nothing changes until you press Apply.

New in 0.9.27: pop-ups you can resize, a graph you can zoom and open in its own window (with property lines and labels that no longer overlap), run progress that keeps your place, an Install RDFLib button in Settings for the file check (NeOn-GPT runs without it if the install does not work), and plainer notes after a NeOn-GPT run.

Since 0.9.26: its own tab, step by step (1 Brief, 2 Inputs, 3 Generate, 4 Review & apply, with Back and Next), the chat always on the right, Apply that no longer gets stuck, Undo that lets you apply again, and Start over.

Tested with Protégé 5.6.7 only. It may not work with other Protégé versions.

After installing, restart Protégé and click the Ontology Copilot tab (or Window > Tabs > Ontology Copilot). Then choose a model provider (OpenRouter, OpenAI, Anthropic, Google Gemini or a local Ollama) and enter your own API key in the plugin's Settings (top right).
